# Family Location Android App

An Android application for consent-based family location sharing, built with Kotlin and Jetpack Compose.

## Overview

This project is the Android client for a family location-sharing system. It is designed to let family members share their location with consent through an Android application connected to a backend service.

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Location:** Google Play Services Location
- **Backend:** Flask and Python
- **Database:** PostgreSQL
- **Hosting:** Render

## Key Components

- `MainActivity.kt` — Main application interface.
- `LocationService.kt` — Location-sharing service and communication with the backend.
- `AndroidManifest.xml` — Application configuration and permissions.

## Privacy Note

Location sharing should be enabled only with the knowledge and consent of participating family members. Do not publish credentials, private configuration files, or personal location data in this repository.
